# homebrew-tap

Homebrew tap for my projects.

```sh
brew tap baojie/tap
brew install tibi          # or, without tapping: brew install baojie/tap/tibi
```

| Name | Kind | Project |
|---|---|---|
| `tibi` | cask | [baojie/tibi](https://github.com/baojie/tibi) — self-hosted image host and pastebin |

Casks and formulae here are updated automatically by each project's release
workflow (GoReleaser). Don't edit them by hand; changes are overwritten on the
next release.
